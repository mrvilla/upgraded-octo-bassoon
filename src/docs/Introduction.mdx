# Design System Lab

This repository converts Figma variables into DTCG JSON, CSS custom properties, and Tailwind 4 theme mappings.

There are no UI components in this milestone. Storybook exists so foundation documentation and theme switching can be verified.

Use the toolbar to switch `data-theme` between light and dark. Semantic colors should change; primitive palette values should not.
