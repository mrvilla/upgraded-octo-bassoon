# Component colors

These are the exported Button and Alert color tokens from `tokens/component/`. They are documented here as tokens, not as production React components.

Aliased tokens paint with `var(--ds-button-…)` / `var(--ds-alert-…)`, so the active color follows the semantic Light/Dark theme.
