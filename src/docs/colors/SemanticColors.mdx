# Semantic colors

Semantic tokens come from `tokens/semantic/light.json` and `tokens/semantic/dark.json`. The colored surfaces use runtime variables such as `var(--ds-color-primary)`, so they follow Storybook’s `data-theme` toolbar.

Paired roles show sample text using the matching foreground token.
