# Dimensions

Figma stores dimensions as unitless floats. Normalization writes structured DTCG values. Original Figma numbers, inferred px units, collection, mode, and scopes are preserved in `$extensions.figma`.

<p>
  Rule: 16px = 1rem for font-size, spacing, and radius. <code>radius.full</code> and border-width stay in px. Opacity stays a unitless number from 0 to 1; CSS output rounds to two decimal places.
</p>
