# Token architecture

This milestone does not connect to a live Figma file. A person exports variables by hand into `figma/export.json`. The repo then runs:

Figma file → manual variable export → `figma/export.json` → DTCG `tokens/` → generated CSS → Tailwind → Storybook.

`figma/export.json` is an immutable snapshot. After conversion, `tokens/` is the source of truth for Style Dictionary. No Figma credentials are required to build.

| Layer | Files | CSS namespace |
| --- | --- | --- |
| Primitive | `tokens/primitive/` | `--primitive-color-*` |
| Semantic | `tokens/semantic/` | `--ds-color-*` |
| Component | `tokens/component/` | `--ds-button-*`, `--ds-alert-*` |
| Dimension | `tokens/dimension/` | `--ds-font-size-*`, `--ds-spacing-*`, `--ds-radius-*`, `--ds-border-width-*`, `--ds-opacity-*` |

Aliases are rewritten with `$collectionName`:

- `{blue.600}` + Primitives → `{color.blue.600}`
- `{primary}` + Semantics → `{color.primary}`

`$extensions.figma.value` stores the original Figma alias path without braces (`blue.600`) because Style Dictionary would otherwise treat `{blue.600}` inside extensions as a live reference. `wasAlias: true` records that it was an alias.

Component tokens are stored, including both Light and Dark files, but they are not implemented as React components and they do not enter Tailwind `@theme`.
